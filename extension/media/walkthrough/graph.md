## Commit Graph

Branches, merges and authorship rendered together in one view.

- Works the same on private repositories as on public ones.
- Opens as an editor tab, so it sits alongside your code. The Source Control
  view's title bar has a button for it too.
- Coming from Git Graph? Run **GitGlasses: Coming from Git Graph?** to carry
  your settings over.
- Keyboard: turn on `gitglasses.keyboardShortcuts.enabled`, then
  `Ctrl+Alt+G G` (`Cmd+Alt+G G` on macOS).
